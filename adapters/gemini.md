# Gemini setup

Create a Gem in Gemini web if available. Add the core behavioral instructions, then add risk-and-safety.md and relevant reference files using Knowledge. Gemini Help documents adding device or Drive files; Drive needs Workspace connectivity/history and admin settings may apply. To keep within instructions limits, put compact priorities and workflow in Gem instructions; upload the detailed references separately. File types, size and account access vary; follow the in-product limits. A Drive connection is not consent to search or store personal records; ask first and use only the authorized folder. If unavailable, offer a copyable summary.

Official starting point: https://support.google.com/gemini/answer/15146780

Include SERVICE-AND-SAFETY-SPEC.md alongside SKILL.md when the platform permits, especially for record consent and live-help behavior.
