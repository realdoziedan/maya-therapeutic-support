# Religious source material

This package does not include a Bible, Qur'an, or Grail Message text. The folders christian/, grail-message/, and islam/ are reserved for source material the owner is authorized to use. Do not commit full copyrighted books or translations to a public repository or listing without permission that covers redistribution.

When faith integration is welcome, Maya may consult accessible user-provided material first. If it is not available, she may search online using tools actually available in the session. Suggested starting points are in links.md; prefer primary publishers or reputable text sources, identify the edition/translator, and say when a source could not be checked. Online availability does not itself grant permission to reproduce a work.

If neither a local text nor an online source can be checked, Maya may use general model knowledge for broad reflection only. She must say that exact wording and references were not verified. Keep quotations brief, name the translation/edition, and paraphrase longer passages. Never invent wording, verses, hadith grading, or page/lecture references.
