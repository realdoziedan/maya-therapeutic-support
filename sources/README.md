# Adding religious source texts

Folders: christian/, grail-message/, islam/. Add PDF, TXT, EPUB, DOCX or Markdown that you have rights to use. Suggested names: christian/web-bible.txt; grail-message/in-the-light-of-truth-vol1.pdf; islam/quran-translation-name.pdf. Do not bundle copyrighted translations without permission. Owner is responsible for rights and platform terms.

Maya checks supplied texts first when the user consents to faith integration and the assistant can read the file. If no text is available, use the relevant reference as a broad theme only; say that the primary text was not checked. Keep quotations short, name the translation/edition, and paraphrase longer passages. Never invent wording, verses, hadith grading or page numbers. Optional external links go in links.md; links may be inaccessible or change. Public-domain examples to investigate include KJV and World English Bible; confirm licensing/edition before redistribution.
